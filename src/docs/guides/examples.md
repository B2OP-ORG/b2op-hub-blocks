# Examples

The **Examples** tab (the 💡 lightbulb in the sidebar) has ready-made programs for the hub.

- **Click** an example to look at its code. It opens read-only, so you can't break it.
- **Right-click** for more:
  - **Open as new project** — makes a new project from the example. A single-file example becomes the project's `main.py`, so you can run it straight away.
  - **Add to current project** — copies the file into the project you're working on.
  - **Download** or **Copy code**.

Some examples are whole folders with several files (like *Project demo*). Opening one as a project keeps all of its files.

Most examples print instructions in the console when they start — such as which port to plug a motor into — so keep an eye on the **Console**.
